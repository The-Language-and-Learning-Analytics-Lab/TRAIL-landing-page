# TRAIL landing page — retired

This standalone site has been merged into the TRAIL platform and is no longer
maintained here.

The landing page now lives at the root route of the platform's Next.js app, in
<https://github.com/The-Language-and-Learning-Analytics-Lab/ai-collaborator>:

- `frontend/app/page.tsx` — the page
- `frontend/app/landing.css` — styles, scoped under `.landing-root`
- `frontend/public/landing/` — screenshots

Edit it there. Changes made in this repository will not be published.

The `index.html`, `css/`, `js/` and `img/` files are kept only as the historical
source that port was made from.

Ported in [ai-collaborator#137](https://github.com/The-Language-and-Learning-Analytics-Lab/ai-collaborator/pull/137).
